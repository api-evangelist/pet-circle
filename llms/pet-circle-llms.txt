# Pet Circle

> Pet Circle is Australia's largest online pet-supplies retailer, selling pet food, flea and
> worming treatments, toys, bedding and prescription veterinary products direct to consumers
> across Australia. Founded in mid-2011 in Sydney as Paws for Life and rebranded in early 2014.
> Pet Circle publishes NO public API, NO developer portal and NO machine-readable API contract.

This file was GENERATED by API Evangelist from the public record on 2026-08-26. It is not
published by Pet Circle. Pet Circle serves no /llms.txt of its own — the path returns the
Vercel Security Checkpoint interstitial (HTTP 429) along with every other storefront path.

## What Pet Circle exposes

- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, gRPC/Protobuf or WSDL contract was found on any
  Pet Circle host.
- No developer portal, API reference, sandbox, changelog, status page or CLI.
- No hosted MCP server and no A2A agent card.
- No /.well-known/ documents of any kind (security.txt, openid-configuration,
  oauth-authorization-server, api-catalog, ai-plugin.json all 404).

## Architecture (public record, not a contract)

- Headless commerce: a commercetools back end with a Vue Storefront / Alokai front end,
  hosted on Vercel; Google Cloud Functions glue SaaS services together.
- Two first-party npm packages exist but are internal storefront libraries, not developer SDKs:
  petcircle-shiba-sdk 0.2.4 and petcircle-shiba-api 0.3.5, both last published 2024-01-18.

## Integrating with Pet Circle

There is no self-serve API. Trading-partner integration is arranged out of band through EDI
onboarding; consumer-side partner traffic runs through third-party affiliate networks
(Commission Factory, Sovrn). Contact Pet Circle directly for either.
